# Base weapon pictures

These are the user-supplied plain weapon pictures, not skin pictures. PNG files are copied without altering their pixels. Matching ignores filename case, spaces, and punctuation; `healing pistol.png` maps to Treatment Pistol.

59 pictures are connected to current catalog entries using each gun’s `image` field. The skin `image` fields remain unchanged.
