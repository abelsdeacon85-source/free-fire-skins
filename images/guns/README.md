# Base weapon pictures

These 74 pictures are user-supplied plain weapon pictures, not skin pictures. PNG pixels have not been altered. Matching ignores filename case, spaces, and punctuation; `healing pistol.png` maps to Treatment Pistol. The filename `hand canon.png` is normalized to `hand-cannon.png`.

All 74 pictures are connected to the 77-weapon catalog using each gun’s `image` field. The 15 additional weapons are now included; their categories are documented in [weapon-categories.md](../../docs/weapon-categories.md). Skin `image` fields remain separate.
